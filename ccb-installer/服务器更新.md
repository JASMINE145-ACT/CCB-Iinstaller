你现在可以先用 **IP + HTTP 方式** 做自动更新服务器，最简单。
因为你的 **443 端口已经被 Reality/Xray 占用了**，所以暂时不要用 Nginx 配 HTTPS 443，避免冲突。

你的更新地址先用：

```text
http://67.216.206.3/ccb-wanding/version.json
```
 ssh -p 39222 -o ConnectTimeout=15 -o PreferredAuthentications=password -o PubkeyAuthentication=no root@67.216.206.3
安装包地址：

```text
http://67.216.206.3/ccb-wanding/CCB-Wanding-1.1.1.exe
```

---

## 第一步：SSH 登录服务器

你现在 SSH 新端口是 `39222`，所以在 Windows PowerShell 里输入：

```powershell
ssh -p 39222 root@67.216.206.3
```

---

## 第二步：服务器安装 Nginx

进入服务器后运行：

```bash
apt update
apt install nginx -y
systemctl enable --now nginx
```

检查：

```bash
systemctl status nginx --no-pager
```

看到 `active (running)` 就可以。

---

## 第三步：创建更新目录

```bash
mkdir -p /var/www/html/ccb-wanding
```

---

## 第四步：从你电脑上传安装包

打包完成后，安装包在 `ccb-installer` 目录（`installer-wanding.nsi` 的 `OutFile` 输出）：

```text
d:\Projects\claude-code-best\ccb-installer\CCB-Wanding-1.1.1.exe
```

你在 **Windows PowerShell** 运行：

```powershell
scp -P 39222 "d:\Projects\claude-code-best\ccb-installer\CCB-Wanding-1.1.1.exe" root@67.216.206.3:/var/www/html/ccb-wanding/
```

注意：

- `scp` 端口用大写 `-P 39222`，不是小写 `-p`。
- 服务器目标目录是 `/var/www/html/ccb-wanding/`（与上文 HTTP 地址一致）。
- 版本号以 `installer-wanding.nsi` 里 `VERSIONMAJOR/MINOR/BUILD` 为准，文件名随之变化。
- 若你复制到别处再上传，把引号内路径换成实际 `.exe` 位置即可。

---

## 第五步：（可选）再上传其它版本包

第四步已上传 `1.1.1`。若要测试「版本列表里选不同包」，把其它 `.exe` 也传到同一目录，例如：

```powershell
scp -P 39222 "d:\Projects\claude-code-best\ccb-installer\CCB-Wanding-1.1.2.exe" root@67.216.206.3:/var/www/html/ccb-wanding/
```

只有单个包时跳过本步，`version.json` 的 `versions` 里只留一条即可。

## 第六步：在服务器写 version.json（多版本清单）

回到服务器 SSH 窗口，运行。**`latest` 决定自动更新提示的目标版本；`versions` 供手动选择列表。**

```bash
cat > /var/www/html/ccb-wanding/version.json <<'EOF'
{
  "latest": "1.1.2",
  "url": "http://67.216.206.3/ccb-wanding/CCB-Wanding-1.1.2.exe",
  "notes": "测试：自动更新会提示安装 1.1.2",
  "versions": [
    {
      "version": "1.1.2",
      "url": "http://67.216.206.3/ccb-wanding/CCB-Wanding-1.1.2.exe",
      "notes": "最新测试包",
      "date": "2026-06-10",
      "size_mb": 308
    },
    {
      "version": "1.1.1",
      "url": "http://67.216.206.3/ccb-wanding/CCB-Wanding-1.1.1.exe",
      "notes": "上一版，可用来测回退安装",
      "date": "2026-06-09",
      "size_mb": 308
    }
  ]
}
EOF
```

然后检查：

```bash
cat /var/www/html/ccb-wanding/version.json
```

**字段说明：**

| 字段 | 作用 |
|------|------|
| `latest` | 后台检查 / 启动提示的「最新版」 |
| `url` | 顶层下载地址（旧客户端兼容；应与 `latest` 对应） |
| `versions` | 版本选择列表（`-Select` 或启动时选「指定版本」） |
| `versions[].url` | **必须与该行 `version` 文件名一致**，不要串版本 |

## 第七步：测试能不能访问

在你电脑浏览器打开：

```text
http://67.216.206.3/ccb-wanding/version.json
```

应能看到带 `latest` 和 `versions` 数组的 JSON，例如：

```text

http://67.216.206.3/ccb-wanding/CCB-Wanding-1.1.1.exe
```

### 本机测试多版本选择

在已安装 CCB-Wanding 的机器上运行：


应出现版本列表（↑↓ 选择，Enter 确认）。也可用桌面/开始菜单的 **「CCB-Wanding 版本选择」** 快捷方式。

## 第八步：确认客户端更新地址

`ccb-check-update.ps1` 内置地址应为：

```powershell
$BuiltInUrl = "http://67.216.206.3/ccb-wanding/version.json"
```

测试时可临时覆盖：

```powershell
$env:CCB_UPDATE_MANIFEST_URL = "http://67.216.206.3/ccb-wanding/version.json"
```

改完后重新打包安装包再发给用户。

## 重要提醒

如果你的用户在中国，而这个 IP 在中国方向访问不稳定，那么自动更新也可能失败。
如果主要用户在印尼，这个 IP 大概率问题不大。

你现在先用这个最简方案跑通：

```text
http://67.216.206.3/ccb-wanding/version.json
```

跑通后，再考虑绑定域名和 HTTPS。
