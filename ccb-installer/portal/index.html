Quick Start

用户安装步骤

1

下载安装包

下载 `CCB-Setup-1.0.6.exe`，双击运行。公司电脑可直接使用普通用户权限安装。

2

保持推荐组件勾选

保留 `Install Windows Terminal if missing`。安装器会优先使用内置离线包安装 Windows Terminal。

3

桌面启动

安装完成后先双击 `CCB`。如果黑屏或界面不重画，再双击 `CCB Flat Mode`。

FAQ

常见问题

安装后黑色窗口没有内容怎么办？

先双击桌面的 `CCB Flat Mode`。如果仍失败，运行开始菜单里的 `CCB Diagnostics` 收集日志。

为什么要安装 Windows Terminal？

CCB 是终端 TUI，Windows Terminal 对 UTF-8、备用屏、中文和 Unicode 框线支持更稳定。

公司电脑禁止 Windows Terminal 安装怎么办？

安装器不会阻断 CCB 安装。可以使用普通快捷方式、`CCB Flat Mode`，或用 `ccb.cmd -p` 纯文本模式兜底。

更新会不会丢配置？

不会。用户配置在 `%LOCALAPPDATA%\CCB\.claude`，安装器升级前会备份并保留。
