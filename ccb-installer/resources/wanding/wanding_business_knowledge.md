## 1) 选型总原则（硬约束）

按下面顺序决策，前一层不满足时不得进入后一层：

1. **品类语义一致性（最高优先）**
2. **关键规格一致性（必须）**
3. **次级属性比较（压力等级/S 系列/品牌）**
4. **来源加权（仅作 tie-breaker，不是一票否决）**

### 1.1 来源规则

- 来源只在"语义与规格都接近"时生效；
- 当来源优先候选与用户语义冲突时（如用户要"热水管"，候选是"冷给水"），**必须降权或排除**。

### 1.2 典型纠偏（热水管案例）

用户：`PPR热水管3/4寸`
如果候选中"字段匹配"有 `热给水直管 dn25 (3/4")`，而"历史报价"是 `冷给水直管 dn25 (3/4")`，应优先热给水直管。
**结论：语义一致性（热/冷）高于来源优先级。**

## 2) 弯头角度（强约束）

- 半弯 => 45°弯头（不得与"弯头"泛化混同）
- 全弯 / 直角弯 => 90°弯头
- 未写"半弯"的"弯头"默认按 90°优先

---

## 3) 主径×副径（A*B / A×B / AB）规则

- 形如 `32*20` / `32×20` / `3220`：A 为主径（dn），B 为副径（英寸侧）
- B 与英寸映射：15/16/20 => 1/2"；25 => 3/4"；32 => 1"；40 => 1-1/4"；50 => 1-1/2"
- A 与 dn 映射：20=>dn20，25=>dn25，32=>dn32，40=>dn40
- 示例：`32*20内丝三通` => 优先 `dn32x1/2"`，不选 `dn32x3/4"`
- 若仅单数值（如 `32弯头`）且无副径，不推断副径

---

## 4) 场景型业务规则

1. 三角阀 != 角阀；仅有角阀候选时判无匹配
2. 软管：库内无软管类产品，询价含"软管"返回无匹配
3. 规格精确匹配优先：dn25 不选 dn20
4. 等径三通优先于异径三通（除非用户明确要异径）
5. `50cm` 表示长度，不得误判为 dn50 管径
6. 电工套管场景：
   - conduit / 电线管 => PVC 电线管(B管)
   - socket => 管直通(套筒)
   - klem / 马鞍卡 => 管夹(U型)
   - tdust 4 cabang => 管四通圆接线盒(带盖)
   - 热熔器 => 焊接机

## 5) 用户纠正沉淀（高优先级）

### 5.1 PVC 直管默认走 D 排水系列

- 默认匹配 **D 排水系列**（白色），不要选 AW 给水系列（贵近一倍）
- DN 允许降级替换：DN110 => DN100(4")，DN75 => DN65(2-1/2")
- 编码示例：DN100 排水 8020012382，DN65 排水 8020012380

### 5.2 PVC 给水 / 排水 / 电线管的语义默认

- 用户只写 `PVC管`、`PVC直管`、`PVC pipe` 且没有说明用途时，优先按 **D 排水系列**理解。
- 用户明确写 `给水`、`AW`、`water supply`、`pressure pipe` 时，选择 AW 给水系列，不要套用 D 排水默认。
- 用户明确写 `排水`、`排污`、`drain`、`drainage` 时，选择 D 排水系列。
- 用户明确写 `电线管`、`穿线管`、`conduit`、`electrical` 时，选择 PVC 电线管 / B 管，不要选给水或排水管。
- 如果同一条询价同时出现给水和排水语义，必须追问用途，不能硬选。

### 5.3 PPR 冷热水与管材/管件选择

- 用户写 `热水`、`hot water` 时，优先热给水/热水管；不要因为历史报价来源优先而选冷给水。
- 用户写 `冷水`、`cold water` 时，优先冷给水/冷水管。
- 用户只写 `PPR管` 且未说明冷热时，可以保留候选并询问冷热/压力等级；不要主动编造。
- `弯头`、`三通`、`直接/直通`、`变径`、`截止阀`、`管帽/堵头` 是不同品类；候选里有明确品类时，不要跨品类替代。
- 用户只写 `弯头` 且未写角度时，默认 90°弯头优先；写 `半弯` 时优先 45°弯头。

### 5.4 PE / HDPE 默认与电熔

- 用户只写 `PE管`、`HDPE管`、`PE给水管` 时，默认按普通给水管/对接体系理解，不主动选择电熔管件。
- 用户明确写 `电熔`、`electrofusion` 时，才选择电熔管件。
- 用户明确写 `对接`、`butt welding` 时，排除电熔候选。
- PE/HDPE 压力等级差异明显时（如 PN10、PN12.5、PN16、0.6MPa、1.0MPa），若用户未给压力且候选接近，必须追问。

### 5.5 胶水、辅材、非管件

- `胶水`、`胶粘剂`、`cement`、`glue` 只能在胶水/胶粘剂类候选中选择，不要选 DN400、400mm 等管材。
- `热熔器` 是工具/焊接机，不是 PPR 热水管或管件。
- `软管` 当前按无直接匹配处理；如用户接受替代，再由用户明确确认。

### 5.6 规格和单位的判断

- `dn/de/od/d + 数字`、`数字mm`、英寸规格是管径；`cm` 通常是长度，不得当作 DN。
- `PN`、`MPa` 是压力等级，不得当作管径。例如 `PN20` 不是 `DN20`。
- `4M/根`、`4m/pcs` 是单根长度，只在用户明确要求长度时作为筛选条件。
- 候选只有相邻规格（如 DN75 与 DN65、DN110 与 DN100）时，除非本知识库已有明确默认，否则应询问用户是否接受替代。

### 5.7 来源优先级的使用边界

- `共同`、`历史报价`、`字段匹配`只能作为最后 tie-breaker。
- 如果历史报价候选与用户品类/用途/冷热/规格冲突，即使来源更高，也要降权或排除。
- 如果字段匹配候选在语义和规格上明显更准确，应优先字段匹配。

## 6) 字段匹配同义与规格

以下规则供字段匹配阶段扩展检索词使用；格式保持 `源词 → 目标词`。

- female thread 内丝 → 内螺纹
- male thread 外丝 → 外螺纹
- half bend 半弯 → 45°弯头
- full bend 直角弯 全弯 → 90°弯头
- elbow 弯 → 弯头
- tee → 三通
- reducer reducing → 异径 变径
- coupling socket → 直通 直接
- electrofusion 电熔 → 电熔
- butt welding 对接 → 对接
- hose 软管 → 软管
- welding machine welder 热熔器 热熔机 → 焊接机
- conduit electrical 电线管 穿线管 → 电线管 B管
- glue cement 胶水 胶粘剂 → 胶水 胶粘剂

## 8) 语言规则（硬约束）

- **所有面向用户的回复必须使用中文**（简体），包括询问、说明、汇总、错误提示。
- 物料编码、规格代号（如 dn50、PE、1.0MPa）、单位、价格、英文品牌名（LESSO、RUCIKA）等专有名词保留原文。
- 印尼/英文表单字段（如 Nama Penawaran、Product number）也保留原文，不翻译。
- 用户使用其他语言（如英文、印尼文）提问时，仍用中文回复，并在必要时附上原文引用。

## 9) 交互规则（查前 vs 查后）

### 查前（match 之前）

缺阻塞参数、keywords 无法推断时（PE 0.6 vs 1.0MPa、冷/热给水、DN 替换策略等）：
- 在 assistant **正文**追问 1~3 个聚焦问题，每题 A/B/C + 你的推荐倾向；可写「请按 `1A 2C` 格式一次回复」。
- **禁止** `AskUserQuestion`。
- **等用户下一条再 match**。

### 查后（match 已返回 `candidate_count > 1`）

**默认：agent 先给结果，不要甩给用户选。**

1. 按 §1–§6 与代码 `_pre_score` tie-break，**同一条回复先输出 1 条推荐价**（编码、名称、单价、一句理由）。
2. 再用 ≤4 条 bullet 列「其他可能」（编码 + 短名称 + 单价即可）。
3. **禁止**「用途 A/B/C / 按 1A 格式 / 请回复序号 1–N」阻塞查价回复。
4. 典型默认：**「直接50」** 无给水/国标语义 → 推荐 **PVC-U 排水**（如 8020020755）；PPR/AW 仅 bullet。

### 仅以下情况才请用户选编码（查后）

- 候选与用户描述**全面冲突**，无法 tie-break
- **仅替代品/降级规格**，且无业务默认（如 PP 无货只能 PPR 替代）
- 用户**明确要求**看全部候选或指定编码

**出单（fill_quotation_sheet）** 写死编码前：若仍属 §9 强制澄清场景，先确认；否则沿用查价推荐项。

- 若用户上一轮已明确选择（如已定 D 排水口径），后续同类型询价**直接沿用**，不必重复问。
- 同一会话已确认的规则（客户等级、含税、DN 替换等）持续生效。
