# CCB-Wanding 2.0.0 — 员工说明

## 这一版最重要的变化

1. **安装更稳**：升级/安装时会自动清理「旧安装残留目录」，减少「无法读取当前安装版本信息」类失败。
2. **助手与技能刷新**：首次启动会按新版本重置 agents / skills（`config_generation` 8）。供应商名录改走 MCP，旧的「供应商名录助手」卡片会被清理。
3. **Word 文档能力**：Word 助手支持 DocumentSpec 结构化出稿（需完整安装后启动一次）。
4. **价库 / 报价 / 任务 / 会话沉淀**等自 1.1.9 以来的开发能力一并入包。

## 安装前请你做

- **完全退出 AionUI**（含右下角托盘图标）。
- 尽量装到系统默认路径（`%LOCALAPPDATA%\Programs\CCB-Wanding`）。
- 若本机有多份历史安装目录，安装向导可能提示清理；请确认后再继续。

## 安装后自检

1. 打开「检查安装 / Check Install」，应显示版本 **2.0.0**。
2. 若 Guid 顶栏仍提示缺少 `.env.accurate`：完全退出后重开一次；仍不行再联系 IT 运行设置修复脚本。
3. 开始菜单可找到 **List Installs** / **Purge Stale Installs**（排查多目录残留）。

## 已知说明

- 现场「双目录」员工机取证不作为本包阻塞项，由 IT 事后抽检。
- 使用「静默安装 `/S`」等于 IT 已预同意自动清理残留树——个人机请用图形安装向导。
