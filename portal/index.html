核心功能

为中文用户量身打造

在原版 Claude Code 基础上，CCB 添加了一系列专为 Windows 中文用户优化的增强功能。

🈲
完整汉化界面
所有菜单、提示、错误信息、帮助文本全部翻译为简体中文，提供原生中文使用体验。
🚀
多种启动模式
支持标准、平铺、安全等多种启动方式，安装后自动在桌面创建各模式快捷方式。
🐚
Git Bash 自动检测
自动扫描并配置 Git Bash 路径，彻底解决 Windows 环境下的 Bash 兼容性问题。
🔌
MCP 服务器支持
内置 MCP 服务器配置管理，轻松接入报价助手、日历等各类工具和外部服务。
📦
一键安装部署
标准 Windows 安装程序，自动处理 Node.js、Bun、Claude Code 的完整安装链。
🛡️
配置无损升级
安装时自动识别并保留现有 Claude Code 配置文件，升级不丢失任何个人设置。
