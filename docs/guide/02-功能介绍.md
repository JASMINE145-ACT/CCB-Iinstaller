# CCB 功能介绍

CCB 是在 Windows 上运行 Claude Code 的完整捆绑包，解决了 Claude Code 官方版本在 Windows 上安装门槛高、依赖缺失、界面纯英文等痛点。

---

## 核心功能

### 1. 一键安装，无需手动配置环境

官方 Claude Code 需要用户自行安装 Node.js / Bun、Git、ripgrep 并配置 PATH。CCB 将这些全部内置：

| 内置组件 | 版本 | 用途 |
|---------|------|------|
| Bun | 1.2.x | JavaScript 运行时，执行 Claude Code |
| Git Bash | 2.54.x | Shell 环境，Claude Code 在 Windows 必需 |
| ripgrep | 14.x | 高速文件搜索（Grep 功能） |
| Windows Terminal | 最新稳定 | 终端仿真器（离线安装） |

### 2. 全界面简体中文

CCB 对 Claude Code 的 dist 文件进行了汉化补丁：

- 欢迎界面、提示信息、菜单文字均为中文
- 错误信息中文化
- 斜杠命令描述中文化

> 汉化使用 `\uXXXX` Unicode 转义写入 JS 文件，避免 Bun 在 Windows 上的编码问题。

### 3. 内置 MCP 服务器

MCP（Model Context Protocol）是让 Claude Code 调用外部工具的协议。CCB 内置：

| MCP 服务器 | 功能 |
|-----------|------|
| exa | 神经网络搜索、URL 内容抓取 |
| excel-mcp | 读写 Excel 文件 |

启动时通过 `--mcp-config ccb-mcp.json` 自动加载，无需用户手动配置。

### 4. 配置隔离，不影响系统环境

CCB 使用独立的配置目录：

```
程序文件：%LOCALAPPDATA%\Programs\CCB\
用户配置：%LOCALAPPDATA%\CCB\.claude\
```

与系统全局 Claude Code（如有）完全隔离，互不干扰。

### 5. 多种启动模式

针对不同使用场景提供四种启动脚本，详见[启动模式文档](./03-启动模式.md)。

### 6. 升级保留配置

覆盖安装时：
- 自动备份现有配置
- 保留用户 `settings.json` 不被覆盖
- 仅更新内置斜杠命令（`commands/modo.md`）

### 7. 完整日志系统

每次启动都会写入日志文件，便于排查问题：

```
%LOCALAPPDATA%\CCB\logs\launcher-xxxx.log   # 启动过程
%LOCALAPPDATA%\CCB\logs\debug-xxxx.log      # Claude Code 调试信息
```

## 目录结构（安装后）

```
%LOCALAPPDATA%\Programs\CCB\
├── ccb.cmd                    # 主启动脚本
├── ccb-diagnose.cmd           # 诊断模式启动
├── ccb-fix-terminal.cmd       # 终端修复工具
├── ccb-flat.cmd               # 平铺模式启动
├── ccb-safe.cmd               # 安全模式启动
├── ccb-text.cmd               # 文本模式启动
├── ccb.ico                    # 图标
├── dist/                      # Claude Code 应用文件（已汉化）
│   └── cli.js                 # 主入口
├── vendor/
│   ├── bun/bun.exe            # Bun 运行时
│   ├── git/                   # 内置 Git Bash
│   ├── ripgrep/               # 搜索工具
│   └── mcp-servers/           # MCP 服务器
├── scripts/
│   ├── ensure-mcp-settings.ps1
│   ├── fix-terminal-launcher.ps1
│   └── patch-i18n.ps1
└── ccb-mcp.json               # MCP 配置（运行时生成）
```

```
%LOCALAPPDATA%\CCB\
├── .claude/
│   ├── settings.json          # 用户配置（保留）
│   └── commands/
│       └── modo.md            # 内置斜杠命令
├── logs/                      # 启动日志
└── backup-before-x.y.z/      # 升级前配置备份
```

## 与官方 Claude Code 的区别

| 特性 | 官方 Claude Code | CCB |
|------|----------------|-----|
| 安装方式 | npm/bun 全局安装 | exe 安装包 |
| 依赖管理 | 手动 | 全部内置 |
| 界面语言 | 英文 | 简体中文 |
| MCP 预配置 | 无 | exa + excel-mcp |
| Windows 适配 | 基础 | 深度优化 |
| 配置隔离 | 共享 `~/.claude` | 独立目录 |
