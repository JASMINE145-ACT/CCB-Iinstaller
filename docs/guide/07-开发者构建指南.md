# 开发者构建指南

本文面向需要修改 CCB、重新打包安装程序、或维护汉化的开发者。

---

## 环境要求

| 工具 | 版本 | 用途 |
|------|------|------|
| NSIS | 3.x | 编译安装程序 |
| PowerShell | 5.1+ | 构建脚本 |
| Git | 任意 | 版本控制 |
| Bun | 1.x（可选） | 运行汉化工具 |

### 安装 NSIS

从官网下载安装：https://nsis.sourceforge.io/Download

默认安装到 `C:\Program Files\NSIS\` 或 `D:\NSIS\`，构建脚本会自动检测。

## 构建流程

### 第一步：准备 vendor 资源

vendor 目录不提交到 git（体积太大），需要手动准备：

**Bun**（必需）：
```powershell
# 下载到 resources/bun/bun.exe（build.ps1 会自动复制到 vendor）
# 或者运行：
.\scripts\build-resources.ps1
```

**ripgrep**（必需）：
同上，由 `build-resources.ps1` 下载。

**Git Bash**（必需，需手动）：
从 https://github.com/git-for-windows/git/releases 下载 `MinGit-x.y.z-64-bit.zip`，解压到：
```
ccb-installer/vendor/git/
```

**MCP 服务器**（可选）：
```
ccb-installer/vendor/mcp-servers/
├── excel-mcp/mcp-excel.exe
└── exa/  （HTTP 类型，无本地文件）
```

### 第二步：运行构建脚本

```powershell
cd D:\Projects\claude-code-best\ccb-installer
.\build.ps1
```

构建脚本会：
1. 检查 NSIS 是否安装
2. 复制 Bun 到 `vendor/bun/`
3. 复制 ripgrep 到 `vendor/ripgrep/`
4. 验证 Git Bash 可用
5. 运行 `makensis installer.nsi`
6. 输出 `CCB-Setup-x.y.z.exe`

## 修改版本号

版本号在两个文件中同步修改：

**installer.nsi**：
```nsi
!define VERSIONMAJOR 1
!define VERSIONMINOR 0
!define VERSIONBUILD 7    ← 修改这里
```

**build.ps1**：
```powershell
$installerName = "CCB-Setup-1.0.7.exe"   ← 修改这里
```

## 汉化维护

### 更新汉化（Claude Code 新版本发布后）

```powershell
# 1. 把新版 dist 文件放入 ccb-installer/dist/

# 2. 运行汉化补丁
.\scripts\patch-i18n.ps1 -DistDir ".\dist"

# 3. 观察输出
#    [updated] chunk-xxx.js  → 成功替换
#    [miss] some english string  → 这个字符串找不到了（可能被改名）
#    [unchanged] chunk-xxx.js   → 此文件无需修改

# 4. 对于 [miss] 的字符串，检查新版中是否改了字符串内容
#    更新 patch-i18n.ps1 中的映射表

# 5. 构建
.\build.ps1
```

### 添加新翻译

在 `patch-i18n.ps1` 的映射表中添加：

```powershell
# 找到对应文件的 $map 定义，添加一行
$map["english string here"] = "中文内容"

# \uXXXX 是中文的 Unicode 转义
# 工具：在浏览器 Console 执行：
# "中文内容".split('').map(c => '\\u' + c.charCodeAt(0).toString(16).padStart(4,'0')).join('')
```

### 安全规则

- **永远不要**在 dist/*.js 文件中直接写中文字符
- 永远使用 `\uXXXX` 转义
- 修改后运行 `patch-i18n.ps1` 的验证函数确认没有 mojibake

## installer.nsi 编码要求

NSIS 安装脚本必须以 **UTF-8 BOM** 保存，否则中文字符无法被 NSIS 正确识别：

```
文件头：EF BB BF（UTF-8 BOM 标记）
```

构建前检查：
```powershell
$bytes = [System.IO.File]::ReadAllBytes("installer.nsi")
$hasBom = $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF
Write-Host "Has UTF-8 BOM: $hasBom"
```

如果没有 BOM，添加：
```powershell
$content = [System.IO.File]::ReadAllBytes("installer.nsi")
$bom = [byte[]](0xEF, 0xBB, 0xBF)
[System.IO.File]::WriteAllBytes("installer.nsi", $bom + $content)
```

## .gitignore 规则

以下内容不提交到 git：

```gitignore
ccb-installer/vendor/bun/        # 体积 ~112MB
ccb-installer/vendor/git/        # 体积 ~110MB
ccb-installer/vendor/ripgrep/    # 体积 ~5MB
ccb-installer/resources/bun/
ccb-installer/resources/ripgrep/
*.exe                            # 编译产物
*.zip
__pycache__/
*.pyc
```

已提交到 git 的内容：
- `dist/chunk-*.js`（已汉化的应用文件，约 10MB）
- 所有 `.cmd`、`.ps1`、`.nsi` 脚本
- `resources/` 中的配置和图标
