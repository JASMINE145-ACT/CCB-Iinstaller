# CCB 启动模式说明

CCB 提供四种启动方式，适配不同的使用场景和终端环境。

---

## 四种模式一览

| 快捷方式 / 脚本 | 适用场景 | 默认安装 |
|---------------|---------|---------|
| `CCB`（ccb.cmd） | 日常使用，推荐 | 是 |
| `CCB 平铺模式`（ccb-flat.cmd） | 窗口管理工具用户 | 可选 |
| `CCB 安全模式`（ccb-safe.cmd） | 排查兼容性问题 | 可选 |
| `CCB 文本模式`（ccb-text.cmd） | 极简终端、自动化 | 可选 |

> 平铺/安全/文本模式快捷方式在安装时默认不选，需要手动勾选。

---

## 主模式：ccb.cmd

**日常使用推荐此模式。**

### 启动行为

1. 检测是否已在 Windows Terminal 中运行
2. 若不在 WT 中，且 `wt.exe` 可用 → 自动在 Windows Terminal 中重新启动
3. 执行环境预检（Bun、Git Bash、dist 文件）
4. 设置中文编码环境（`LANG=zh_CN.UTF-8`）
5. 加载 MCP 配置
6. 启动 Claude Code

### 鼠标与滚动

```
CLAUDE_CODE_DISABLE_MOUSE=1          # 关闭 TUI 鼠标捕获
CLAUDE_CODE_DISABLE_VIRTUAL_SCROLL=1 # 关闭虚拟滚动
```

关闭 TUI 鼠标捕获后，**Windows Terminal 原生滚轮**接管滚动，效果：
- 鼠标滚轮 → 滚动终端历史
- 鼠标拖动 → 选中文字（复制）

### 关键环境变量

```cmd
LANG=zh_CN.UTF-8          # 中文编码
CCB_CONFIG_DIR            # 用户配置目录
CLAUDE_CODE_GIT_BASH_PATH # 内置 bash.exe 路径
ANTHROPIC_BASE_URL        # API 入口（MiniMax 代理）
```

## 平铺模式：ccb-flat.cmd

**适合配合窗口管理工具（如 PowerToys FancyZones）使用。**

与主模式的区别：
- 不尝试自动切换到 Windows Terminal（更稳定地在当前窗口运行）
- 禁用全屏交替缓冲区（alternate screen），输出保留在终端滚回区
- 适合多窗口平铺布局

### 何时用平铺模式

- 你使用窗口管理器，希望 CCB 在固定位置的窗口中运行
- 你希望关闭 CCB 后，命令输出仍然可以向上滚动查看

---

## 安全模式：ccb-safe.cmd

**适合排查兼容性问题、遇到启动异常时使用。**

特点：
- 关闭所有可能导致兼容性问题的高级终端特性
- 使用最基本的 I/O 模式
- 不尝试重新在 WT 中启动

### 何时用安全模式

- 主模式启动失败、界面花屏、字符乱码
- 在不支持 VT 转义的旧版终端中运行
- 需要通过管道捕获输出时

---

## 文本模式：ccb-text.cmd

**适合极简环境或脚本自动化。**

特点：
- 完全禁用 TUI（无彩色、无交互界面）
- 以纯文本形式输出
- 适合重定向输出到文件

### 示例

```cmd
# 把对话输出保存到文件
ccb-text.cmd > output.txt 2>&1
```

---

## 诊断模式：ccb-diagnose.cmd

**不是日常启动方式，用于排查问题。**

```cmd
# 普通诊断
ccb-diagnose.cmd

# 重现窗口大小调整崩溃
ccb-diagnose.cmd --repro-resize
```

诊断模式会：
- 打印详细的启动环境信息
- 写入带时间戳的日志文件
- 启动结束后保持窗口打开，显示退出码和日志路径

日志位置：
```
%LOCALAPPDATA%\CCB\logs\ccb-YYYY-MM-DD-HH-MM-SS.log
```

## 手动启动（命令行）

在 PowerShell 或 cmd 中手动启动 CCB，并指定工作目录：

```powershell
# 在指定目录启动
& "$env:LOCALAPPDATA\Programs\CCB\ccb.cmd" "C:\你的项目"

# 禁用 Windows Terminal 自动重启（在当前窗口运行）
$env:CCB_DISABLE_WT_RELAUNCH=1
& "$env:LOCALAPPDATA\Programs\CCB\ccb.cmd"
```

## 模式选择建议

```
日常开发
  └── 主模式（ccb.cmd）

窗口平铺布局
  └── 平铺模式（ccb-flat.cmd）

启动有问题 / 界面异常
  └── 安全模式（ccb-safe.cmd）
      └── 还不行？→ 诊断模式（ccb-diagnose.cmd）

脚本 / 自动化 / 无 TUI 环境
  └── 文本模式（ccb-text.cmd）
```
