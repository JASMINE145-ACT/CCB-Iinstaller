# CCB 快速开始

CCB（Claude Code Bundle）是 Claude Code 的 Windows 一键安装包，内置所有运行依赖，无需手动配置环境。

---

## 系统要求

| 要求 | 说明 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| 磁盘空间 | 约 500 MB |
| 网络 | 需要能访问 API 服务（Anthropic / MiniMax） |
| 权限 | 普通用户权限即可，无需管理员 |

---

## 第一步：下载安装包

从仓库 Releases 页面下载最新版本：

```
CCB-Setup-1.0.7.exe
```

不要使用 1.0.4 及更早版本，缺少 MCP 和终端修复。

---

## 第二步：安装

1. 双击 `CCB-Setup-1.0.7.exe`
2. 安装语言为简体中文，点击下一步
3. **安装目录**：默认 `%LOCALAPPDATA%\Programs\CCB`，可自定义（建议用默认）
4. **组件选择**：
   - Bun 运行时（必选）
   - ripgrep（必选）
   - Git Bash（必选）
   - MCP 服务器（必选）
   - Windows Terminal（推荐勾选）
   - 创建桌面快捷方式（推荐勾选）
   - 桌面附加快捷方式（可选，高级用户）
5. 点击安装，等待完成

安装结束后桌面会出现 **CCB** 图标。

---

## 第三步：启动

双击桌面 **CCB** 图标。

- 如果已安装 Windows Terminal，CCB 会自动在其中打开
- 首次启动会进行环境预检（几秒钟）
- 看到 Claude Code 的欢迎界面即为成功

---

## 第四步：开始使用

进入 CCB 后，你可以：

```
# 在任意目录启动，CCB 会把该目录作为工作区
# 例如在某个代码项目目录下双击 CCB 快捷方式

# 或在 Windows Terminal 中手动启动：
& "$env:LOCALAPPDATA\Programs\CCB\ccb.cmd" C:\你的项目路径
```

---

## 升级

直接运行新版安装包覆盖安装，**不需要先卸载**。

升级前安装器会自动备份用户配置到：
```
%LOCALAPPDATA%\CCB\backup-before-1.0.7\
```

如果从旧版升级出现问题，建议先卸载再重装：
1. 开始菜单 → CCB → 卸载 CCB
2. 重新运行新版安装包

---

## 卸载

开始菜单 → `CCB (Claude Code Best)` → `卸载 CCB`

> 用户配置目录 `%LOCALAPPDATA%\CCB\.claude` 不会被删除，需要手动清理。
