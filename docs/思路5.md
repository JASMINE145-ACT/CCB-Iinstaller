## AionUI 主体 + CCB 业务能力接入方案

### 一、整体思路

本方案以 **AionUI 作为主要界面和 Agent 运行环境**，不再强行复刻或改造 CCB-Wanding 的完整 runtime。CCB-Wanding 的核心业务能力将被拆分为一组可调用的业务工具，通过 MCP Server 或插件方式接入 AionUI。

简单来说：

**AionUI 负责界面、对话体验、Agent 调度和工具调用展示；CCB 负责提供库存查询、Accurate 数据处理、业务规则检索、报表生成等实际业务能力。**

整体架构如下：

```text
AionUI
  ↓
AionUI 内置 Agent / 模型
  ↓
CCB Business MCP Server
  ├─ 库存查询工具
  ├─ Accurate 汇总工具
  ├─ 报价规则查询工具
  ├─ 业务知识库检索工具
  └─ 报表生成与保存工具
```

---

### 二、为什么这样做

相比继续改造 CCB-Wanding runtime 或强行适配 AionUI 协议，这个方案实现难度更低，稳定性更好，也能最大程度保留 AionUI 的界面优势。

AionUI 本身已经具备较完整的 AI 工作台能力，包括对话界面、工具调用展示、文件处理、多模型配置等功能。因此，我们不需要重新开发一套复杂 UI，也不需要维护 AionUI 前端 fork。

CCB 只需要专注做好业务能力，例如查库存、查 Accurate、读取业务规则、生成客户汇报等。

---

### 三、核心功能

第一阶段可以先接入以下几个工具：

1. **inventory_search**
   用于查询库存数据，支持按 SKU、产品名称、仓库、日期等条件检索。

2. **accurate_summary**
   用于处理 Accurate 数据，支持汇总销售、库存、财务或客户相关数据。

3. **quotation_rule_lookup**
   用于查询报价规则、业务规则、价格说明和操作规范。

4. **knowledge_search**
   用于检索公司内部知识库，例如业务流程、产品说明、客户案例、常见问题等。

5. **save_report**
   用于保存模型生成的结果，例如报价单、客户汇报、Excel 文件或 Markdown 文档。

---

### 四、数据与知识库设计

业务知识、规则文档、模板文件可以统一放在云端或共享目录中，例如：

```text
knowledge/
├─ quotation/
├─ inventory/
├─ accurate/
├─ customer_cases/
├─ templates/
└─ workflow/
```

AionUI 通过 CCB MCP Server 调用这些数据，不直接操作底层文件。这样可以保证权限、安全和数据一致性。

后续可以增加版本管理和审核机制，避免员工随意修改正式规则。

---

### 五、实施步骤

第一步，先跑通 AionUI 本体，确认其模型配置、MCP 工具调用和文件展示功能正常。

第二步，开发 CCB Business MCP Server，先实现库存查询、Accurate 汇总和知识库检索三个核心工具。

第三步，把 CCB MCP Server 注册到 AionUI 中，让 AionUI Agent 可以调用这些业务工具。

第四步，整理业务规则文档和数据目录，将常用规则、报价说明、库存字段说明、Accurate 使用说明统一放入知识库。

第五步，测试真实业务场景，例如“查询某个 SKU 的库存”“根据 Accurate 数据生成客户汇报”“根据报价规则生成报价建议”。

---

### 六、方案优点

这个方案的最大优点是实现快、界面好看、风险低。

AionUI 负责成熟的 AI 交互体验，CCB 负责业务工具和数据能力，两者职责清晰。相比从零开发 UI 或强行复刻 CCB-Wanding runtime，这条路线更适合快速做出可用版本。

---

### 七、方案限制

这个方案的代价是：CCB-Wanding 不再是主 runtime。

也就是说，Agent 的任务规划、上下文管理、工具选择和模型调用主要由 AionUI 控制。CCB-Wanding 更像是一组业务能力插件，而不是完整的大脑。

如果未来希望 CCB-Wanding 完全掌控 runtime，可以再单独做 CCB Runtime-first 版本。但第一阶段为了快速上线和保证界面体验，可以先采用 AionUI 主体方案。

---

### 八、最终定位

本方案可以定位为：

**基于 AionUI 的 CCB 业务 AI 助手。**

它的目标不是完整复刻 CCB-Wanding，而是利用 AionUI 的成熟界面和 Agent 能力，快速接入 CCB 的库存、Accurate、报价规则和业务知识库，先做出一个员工可用、界面高级、业务能力明确的内部 AI 工作台。
