## AOL inventory BOM fix (closed — 2026-06-28)

**Symptom:** Guid `get_inventory_by_code` → `inventory_unavailable` /「AOL 凭证未配置」while health **29/29 + probe PASS**.

**Root cause:** (1) `.env.accurate` written with UTF-8 BOM → dotenv key `\ufeffAOL_ACCESS_TOKEN`; (2) `python-spawner.js` passed empty `AOL_*` strings blocking dotenv fallback.

**Fix applied (repo + `D:\CCB-Wanding`):**

| Artifact | Change |
|----------|--------|
| `ensure-wanding-settings.ps1` | `WriteAllText` UTF-8 no BOM |
| `python/main.py`, `client.py` | `load_dotenv(..., encoding="utf-8-sig")` |
| `python-spawner.js` | Delete empty `AOL_*` before spawn |
| `test-mcp-health.ps1` | BOM check + `dotenv_values` parse (len≈484) |

**Post-fix verification:**

| Check | Result |
|-------|--------|
