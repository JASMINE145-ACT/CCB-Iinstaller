## Root cause

`D:\claude-code-B\src\services\acp\bridge.ts#forwardSessionUpdates()` handled
assistant-role `tool_use`, but discarded every user-role SDK message.
QueryEngine emits tool results as user-role messages containing
`tool_result`/`mcp_tool_result`. The bridge therefore sent a pending tool call
to AionUI but never sent its completed/failed update. SDK transcript repair
later rendered the orphan as `[Tool use interrupted]`.

This was an ACP producer bug, not quotation Python, LKG, org 401, AOL
credentials, MCP registration, or the old 60-second timeout.
