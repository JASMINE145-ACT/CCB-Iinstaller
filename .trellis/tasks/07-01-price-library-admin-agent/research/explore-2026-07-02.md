# Explore — price-library-admin-agent (2026-07-02)

## Question

是否需要新建 agent 管理价格库（改值、改列名、删、增等）？

## Findings

### 1. 服务端已就绪，Agent 层空白

- AionCore `POST /api/price-library/draft/items` + import/publish/revert 已在 runbook 登记
- `org_price_client.py` **仅读**（active / LKG / bundled seed）
- 无 Python admin client、无 MCP 写工具、无专用 agent
- AionUI `#/price-library` **只读**（06-27 task deferred PR4）

### 2. 「改列名」≠ Agent 能力范围

- Org schema 固定 41/42 列（`data.Md`）
- 用户口语「改列名」应解释为字段语义（Read data.Md）
- 真删列/增列 = AionCore migration，单开任务

### 3. 与 quotation-agent 必须分离

- quotation：全员读 + 出单
- price-library-admin：price_admin 写 + publish
- 禁止 quotation-agent 直接改中心库（参照 knowledge shadow 事故）

### 4. 批量 vs 单点

| 场景 | 路径 |
|------|------|
| 改 1~N 个编码的若干字段 | draft/items API |
| 全量/大范围更新 | prepare → import/preview → apply → publish |
| skipped.json / 列瘦身 | 脚本层规范化，非 agent 主路径 |

### 5. 权限与 CSRF

- `PRICE_ADMIN_USERNAMES` env；非 UI 授予
- POST 需 CSRF cookie + `x-csrf-token`（同 org-knowledge）
- 复用 `admin/org_session.py` profile 对齐（07-02）

## Recommendation

新建 `price-library-agent` + `org_price_admin_client` + **独立** `price-library-server` MCP；不扩 quotation-agent 写权限。
