# 侧栏「数据库」折叠分组

## Goal

侧栏顶部将「知识库」「价格库」两个平级入口合并为可折叠父级 **数据库**，展开后显示子项；侧栏 icon-only 时用单图标 + 下拉菜单。

## Acceptance

- [ ] 展开侧栏：「任务」下方显示「数据库」分组标题，可折叠；展开后显示「知识库」「价格库」
- [ ] 访问 `#/org-knowledge` 或 `#/price-library` 时分组自动展开，对应子项高亮
- [ ] 折叠侧栏：单「数据库」图标；点击弹出菜单可选知识库 / 价格库
- [ ] 未配置 `org-server.json` 时整块不显示（与现行为一致）
- [ ] 路由、页面、IPC 无变更
