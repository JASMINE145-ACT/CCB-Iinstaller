• 可以。正确路径核心是：不要直接在 minified chunk 里写裸中文，尽量写 \uXXXX 转义；先找“文案来源类型”，再
  分层处理。                                                                                            
                                                                                                        
  汉化路径                                                                                              
                                                                                                        
  1. 先定位文案来源                                                                                     
     用 rg 搜原文：                                                                                     
                                                                                                        
  rg -n -F "Did not add a working directory" ccb-installer                                              
                                                                                                        
  常见来源：                                                                                            
                                                                                                        
  - / 命令列表描述：dist/chunks/loadAgentsDir-*.js                                                      
  - bundled skill 描述：dist/chunks/main-*.js                                                           
  - 命令执行结果：具体命令 chunk，如 add-dir-*.js、assistant-*.js                                       
  - MCP prompt 描述：通常来自 MCP server 运行时，需要在命令显示层做映射，不要硬改 exe                   
  - 安装器文案：installer.nsi                                                                           
  - 启动脚本：ccb.cmd                                                                                   
                                                                                                        
  2. 只改用户可见文案                                                                                   
     优先改：                                                                                           
                                                                                                        
  - description                                                                                         
  - children                                                                                            
  - title
  - placeholder                                                                                         
  - display:"system" 的消息                                                                             
  - onCancel/onDone/onError 结果消息                                                                    
                                                                                                        
  谨慎改或不改：                                                                                        
                                                                                                        
  - prompt 给模型看的英文                                                                               
  - tool schema / 参数名                                                                                
  - 环境变量名                                                                                          
  - HTTP、SDK、底层库错误                                                                               
  - MCP 工具名、命令名                                                                                  
                                                                                                        
  3. 在 JS chunk 里用转义中文                                                                           
     推荐：                                                                                             
                                                                                                        
  e(`\u672a\u6dfb\u52a0\u5de5\u4f5c\u76ee\u5f55\u3002`)                                                 
                                                                                                        
  不要写：                                                                                              
                                                                                                        
  e(`未添加工作目录。`)                                                                                 
                                                                                                        
  因为某些构建/写文件路径可能会把裸中文破坏成：                                                         
                                                                                                        
  e(`????????`)                                                                                         
                                                                                                        
  4. 同步写入补丁脚本                                                                                   
     不要只改 dist/chunks/*.js。还要把规则写进：                                                        
                                                                                                        
  ccb-installer/scripts/patch-i18n.ps1                                                                  
                                                                                                        
  否则重新打包或重新跑汉化脚本会丢。                                                                    
                                                                                                        
  建议用类似结构：                                                                                      
                                                                                                        
  $chunkCommandResultMessages = New-ReplacementMap                                                      
  $chunkCommandResultMessages['e(`Did not add a working directory.`)'] =                                
    'e(`\u672a\u6dfb\u52a0\u5de5\u4f5c\u76ee\u5f55\u3002`)'                                             
  Patch-AllChunks -DistDir $ChunksDir -Replacements $chunkCommandResultMessages                         
                                                                                                        
  5. 改完必须验证                                                                                       
     至少跑：                                                                                           
                                                                                                        
  node --check ccb-installer\dist\chunks\xxx.js                                                         
                                                                                                        
  如果是 loadAgentsDir 这种复杂 chunk，还要用 Bun 验证：                                                
                                                                                                        
  .\ccb-installer\vendor\bun\bun.exe ccb-installer\dist\chunks\loadAgentsDir-BMosMfSG.js                
                                                                                                        
  再验证启动：                                                                                          
                                                                                                        
  $env:CCB_NO_PAUSE='1'                                                                                 
  $env:CCB_DISABLE_WT_RELAUNCH='1'                                                                      
  D:\CCB\ccb.cmd --version                                                                              
                                                                                                        
  6. 同步当前安装目录                                                                                   
     源码改完后，当前 D:\CCB 不会自动变化，需要复制：                                                   
                                                                                                        
  Copy-Item ccb-installer\dist\chunks\xxx.js D:\CCB\dist\chunks\xxx.js -Force                           
  Copy-Item ccb-installer\scripts\patch-i18n.ps1 D:\CCB\scripts\patch-i18n.ps1 -Force                   
                                                                                                        
  7. 重新打包                                                                                           
                                                                                                        
  cd D:\Projects\claude-code-best\ccb-installer                                                         
  .\build.ps1 -NoPause                                                                                  
                                                                                                        
  8. 最后扫乱码和残留英文                                                                               
                                                                                                        
  rg -n "\?\?\?\?|Did not add|KAIROS \?" ccb-installer\dist\chunks                                      
  rg -n -F "原英文文案" ccb-installer\dist\chunks                                                       
                                                                                                        
  经验规则                                                                                              
                                                                                                        
  - 命令名不要翻译：/add-dir、/assistant 保留。                                                         
  - 产品名可保留：Claude Code、KAIROS、Excel MCP。                                                      
  - 参数名保留：--format、--label、<path>。                                                             
  - 用户看到的解释、按钮、状态、错误、取消、成功消息要翻译。                                            
  - 裸中文进入 chunk 前要非常谨慎，最好统一转义。                                                       
  - 如果出现 ????，说明文件内容已经坏了，要从原英文或上下文重新替换成 \uXXXX，不是调终端编码能解决的。
